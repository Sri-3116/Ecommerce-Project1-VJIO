# VJIO – Fashion E-Commerce Website

VJIO is a modern and responsive fashion e-commerce website designed to provide users with a stylish and smooth online shopping experience.

## 🚀 Features

- 📱 Fully responsive design for desktop, tablet, and mobile devices
- 🧭 Responsive navigation bar with mobile sidebar menu
- 🖼️ Hero image slider with navigation buttons
- 🏷️ Promotional offer banner
- 👕 New Arrivals section
- 🛍️ Bestsellers / Most Wanted section
- ❤️ Wishlist heart button interaction
- 🏢 Popular brands showcase
- ⚡ Limited-time offer section
- 📧 Newsletter subscription form
- 📱 Mobile-friendly layout
- 🎨 Modern and attractive fashion UI design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Google Fonts
- Font Awesome

## ⚙️ JavaScript Functionality

JavaScript is used to create interactive features such as:

- Closing the promotional advertisement banner
- Hero image slider navigation
- Opening and closing the mobile sidebar menu
- Automatically closing the sidebar when a navigation link is clicked
- Toggling wishlist heart icons
- Scroll-based section animations
